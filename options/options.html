ReLeet settings

LeetCode

When a submission on leetcode.com is Accepted, ReLeet asks right there how hard it felt. It also checks your public recent accepted submissions every 15 minutes while Chrome is running, which catches solves on other devices.

The first check only notes what's already there, so past solves aren't queued. Import recent adds your most recent accepted problems (about 20) that aren't tracked yet to the popup for rating.

Calendars

Each connected account gets its own calendar named “ReLeet” with a block for every upcoming review, and a reminder before it. Re-rating a problem moves its block; deleting the problem deletes it.

Schedule

Block length by last rating

Reminder:

Reviews on the same day are placed back to back from the start time, every day including weekends. Changing these moves upcoming blocks in connected calendars; blocks that already started stay where they are.

Notifications

ReLeet notifies you when a review is due, and when the background check finds a solve to rate.
