Faster updates (optional)

The repo is checked right after you submit on neetcode.io. Submissions made elsewhere are caught by background polling. Without a token, GitHub allows 60 requests/hour, so that polling runs every 15 minutes (and whenever you open the popup). With a token the limit is 5,000/hour and the repo is checked every minute.

Create a fine-grained token with Repository access: Public repositories (read-only) and no extra permissions. It is stored only in this browser's extension storage.

Sync

The first sync only records the latest commit, so older submissions are skipped. Use Import existing problems to add every problem already in the repo to the popup for rating.
